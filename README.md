## 🟣 About Me

I'm a recent **BSc Software Engineering** graduate from **De Montfort University**, about to begin an **MSc in Artificial Intelligence**. My focus sits at the intersection of **full-stack product engineering** and **applied AI/ML** — building things that go from idea to a working, tested, real-world product rather than staying on paper.

My final year project, **CragCrowd**, is a full-stack Android application (Kotlin, Jetpack Compose, Firebase) built for the climbing community, graded **80/100**. Alongside it I built **CragBot**, an LLM-integrated companion tool, and **JankEdit**, a personal IDE built from scratch — both driven by curiosity about how far I could push a stack I already knew well.

I care about **clean architecture (MVVM)**, **shipping working software over slideware**, and **AI systems that are actually useful**, not just impressive in a demo.

## 🟣 Featured Projects

<details open>
<summary><b>🏔️ CragCrowd — Social Platform for Climbers</b></summary>
<br/>

Final year software engineering project: a full-stack Android application connecting climbers around crag information, route logging, and community discovery. Built end-to-end using MVVM architecture with a real-time Firebase backend.

| Category | Detail |
|---|---|
| **Stack** | Kotlin, Jetpack Compose, Material Design 3, MVVM, Firebase Auth, Firestore, Firebase Storage, Google Maps SDK |
| **Scale** | Full production-style Android app, single-developer build |
| **Performance** | Real-time data sync via Firestore listeners; optimized Compose recomposition |
| **Security** | Firebase Auth with scoped Firestore security rules |
| **Impact** | Graded **80/100** — final year dissertation project |
| **Repository** | `https://github.com/JoeRilez/DevelopmentProject` |

CragCrowd was designed around real climber workflows — discovering crags, logging sends, and sharing conditions — with an architecture built to scale beyond a single university project into a genuinely usable tool.

</details>
